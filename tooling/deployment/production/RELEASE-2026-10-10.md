## Lệnh vận hành hiện hành

CRM, tại `/opt/x3crm` (file `.env` vẫn được Compose dùng để nội suy cấu hình DB/Reverb):

```sh
set -a; . ./crm.release.env; set +a
docker compose -f compose.yml -f compose.crm-zalo.yml -f compose.crm-release.yml config --quiet
docker compose -f compose.yml -f compose.crm-zalo.yml -f compose.crm-release.yml up -d --no-deps backend frontend scheduler queue-worker reverb
docker exec x3crm-nginx-1 nginx -t
docker exec x3crm-nginx-1 nginx -s reload
```

Không dùng deploy script cũ/compose.yml đơn lẻ: sẽ bỏ overlay image, identity và volume. Mỗi release migration phải thực hiện tường minh sau backup, trước bật worker.

Zalo, tại `/opt/x3-zalo-team/tooling/zalo-team/service`:

```sh
set -a; . ./api.release.env; set +a
docker compose -f compose.vps-local.yml -f compose.drive.yml -f compose.campaigns.yml -f compose.release.yml up -d --no-deps --no-build api sync backup drive campaigns
docker compose --env-file frontend.release.env -f compose.frontend.yml up -d --no-deps frontend
```

Web connector, tại `/opt/x3-zalo-team/tooling/zalo-team/web`: dùng `compose.yml` + `compose.campaigns.yml` + `compose.release.yml`; file cuối đặt image release mới. Trước restart kiểm tra gateway gọi rảnh và không có chiến dịch đang gửi.

Scheduler CRM chạy `zalo-team:deliver-documents`, `zalo-team:work-reminders` mỗi phút, prune tài liệu lúc 02:20 theo timezone ứng dụng. Không cần chạy thêm worker tài liệu/watch song song.
